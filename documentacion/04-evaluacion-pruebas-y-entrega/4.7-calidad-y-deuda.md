## Linter

El API trae ESLint 9 (`api/eslint.config.mjs`, script `npm run lint` con `--fix`). **En este expediente se corrió sin `--fix`** para no reescribir el prototipo:

```bash
cd api
npx eslint "src/**/*.ts" "test/**/*.ts"
```

Resultado real, 25 de noviembre de 2026: **411 errors, 9 warnings**. La mayoría es `prettier/prettier` (saltos de línea) y reglas `@typescript-eslint/no-unsafe-*` / `require-await` en los tests. No se afirma «0 errores».

El cliente web **no** tiene ESLint ni script `lint` en `web/package.json`. No se añadió uno: no hay paquete de lint que cablear. La constancia de calidad del front en T6 es Vitest + umbrales de `web/vite.config.ts`.

No hay regresiones de producto respecto de T5: las HU Must 01–11 siguen en `main`. Lo que sí aparece al medir de nuevo es el margen estrecho del umbral de ramas/funciones ([issue #21](https://github.com/juliodparada-bit/plataforma-refugios-fauna-domestica-bogota/issues/21)).

## Los backends vistos en formación y Nest en Mestizo

El expediente **no** lista un pensum oficial de cuatro motores. Lo que sí está escrito es: un solo backend, NestJS 11 + TypeScript + Prisma + PostgreSQL; y, **si el centro exigiera Java**, Spring Boot sustituye a Nest sin cambiar capas ni RF ([2.1](../02-planeacion-y-diseno/2.1-arquitectura-de-la-solucion.md)).

Frente a los backends vistos en formación (el ciclo ADSO trabaja varios; aquí no se inventan marcas ni versiones de aula), Nest en Mestizo se justifica así:

| Responsabilidad | Cómo la cubre Mestizo |
|---|---|
| Un API, no cuatro | Un proceso Nest. Web y Flutter son clientes. |
| Validación de entrada | `ValidationPipe` + DTO (`class-validator`). |
| Identidad | JWT firmado, bcryptjs costo 12, cookie `sid` httpOnly y Bearer. |
| Autorización | `SesionGuard`, `RolesGuard`, sello para publicar. |
| Persistencia | Prisma = DER del 2.3. No hay segundo motor «por probar». |
| Lo que no hace | No hay pasarela, recaudo ni capa IoT. |

La diferencia que se puede mostrar en la oral: el 4.° backend no es un CRUD suelto; son guards, Prisma y dos formas de transportar el mismo JWT.
