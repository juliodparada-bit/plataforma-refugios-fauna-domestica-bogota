## Qué cierra T6

En `main` (commit `ccac6b5`, merge del [PR #17](https://github.com/juliodparada-bit/plataforma-refugios-fauna-domestica-bogota/pull/17) sobre el código del [PR #11](https://github.com/juliodparada-bit/plataforma-refugios-fauna-domestica-bogota/pull/11)) el prototipo **Mestizo** deja demostrable:

- Historias Must **HU-01 a HU-11** (módulos 1 a 5 del tablero [3.5](../03-ejecucion-y-desarrollo/3.5-tablero-de-ejecucion.md)).
- API NestJS con validación de entrada (`ValidationPipe` + DTO) y JWT: cookie `httpOnly` `sid` en la web y `Authorization: Bearer` en Flutter ([2.1](../02-planeacion-y-diseno/2.1-arquitectura-de-la-solucion.md), [3.1](../03-ejecucion-y-desarrollo/3.1-entorno-de-desarrollo.md), [api/README.md](../../api/README.md)).
- Cliente web React + Vite en el puerto 5173 y companion Flutter en `mobile/` (no hay publicación en tiendas).
- Demo de punta a punta en local (Postgres 5433, API 3000, web 5173). Guion: [4.5](4.5-sustentacion.md). Diapositivas: [http://localhost:5173/sustentacion](http://localhost:5173/sustentacion).
- Pruebas de las semanas 1 a 4 fusionadas en `main` por los PR **#6, #7, #9 y #11**. Umbral S4 de API en `main` por el **#17** (88 / 88 / 92 / 70 = max(50, medición 88 redondeada abajo)). Front 75 / 75 / 77 / 70 y `testTimeout` 20 s no se tocaron. Detalle en [4.1](4.1-pruebas.md).

**IoT:** no aplica. El producto no incluye sensores ni hardware. No hay bonificación D2 por este ítem.
