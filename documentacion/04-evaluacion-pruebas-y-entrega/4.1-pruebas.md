## Colección Postman

Archivo importable: [`tests/postman/mestizo-api.postman_collection.json`](../../tests/postman/mestizo-api.postman_collection.json).

1. Abrir Postman → Import → seleccionar ese JSON.
2. Levantar la API (`cd api && cp .env.example .env && npm run start:dev`) con Postgres en 5433 y semilla.
3. Variable `baseUrl` = `http://localhost:3000`.
4. Correr primero los dos `POST /auth/entrar` de piloto para llenar `tokenAdoptante` y `tokenEntidad`.
5. Cada request tiene `pm.test` de código de estado (200, 201, 400, 401, 403, 409).

Rutas cubiertas: `GET /localidades`, `POST /auth/entrar` (ok, 401, 400), `GET /auth/yo` (sin sesión 200 y con Bearer), `POST /auth/registro` (409 de correo existente y 400 sin consentimiento), `GET /animales`, `GET /animales/mios` (401 / 403 / 200).

Un registro **201** exige un correo que no exista y un `localidadId` real de `GET /localidades`. No se deja un UUID inventado como caso positivo.

Complemento en Jest (no es Postman): `api/src/contrato.http.test.ts` y `api/src/animales/animales.api.test.ts`.

## Ciclos detectar → corregir → verificar

### Ciclo 1 — timeout del recorrido (cerrado en `main`)

1. **Detectar.** El recorrido de `App` con cobertura superaba 5 s (S3, Brayan, PR #9). Issue [#18](https://github.com/juliodparada-bit/plataforma-refugios-fauna-domestica-bogota/issues/18).
2. **Corregir.** Commit [`040b6c4`](https://github.com/juliodparada-bit/plataforma-refugios-fauna-domestica-bogota/commit/040b6c43e8d3c762970b0efc655e1cbedc37b223): `testTimeout: 20000` en `web/vite.config.ts`.
3. **Verificar.** El archivo en `main` tiene 20000. El job de CI del merge del PR #11 pasó. En esta máquina los 25 tests de web corren; el comando falla por umbral de cobertura, no por timeout.

### Ciclo 2 — mutante `role="alert"` (cerrado en `main`)

1. **Detectar.** Quitar `role="alert"` → Playwright `element(s) not found` (S1). Issue [#19](https://github.com/juliodparada-bit/plataforma-refugios-fauna-domestica-bogota/issues/19). Matriz de rotación.
2. **Corregir.** Se conservó el atributo en `Entrar.tsx`.
3. **Verificar.** El E2E y el `role="alert"` están en `main` (PR #6). El test de front `Entrar.test.tsx` también busca `role=alert` (CP-03).

### Ciclo 3 — tope 80 → 90 / varchar(80) (abierto; no está en `main`)

1. **Detectar.** Mover el tope de 80 a 90 caracteres tumba el test de servicio; el HTTP sigue por `@MaxLength(80)`. En S6 el PR #14 cubre `varchar(80)`, `TRUNCATE` y el puerto **5434**. Issue [#21](https://github.com/juliodparada-bit/plataforma-refugios-fauna-domestica-bogota/issues/21).
2. **Corregir / verificar.** Pendiente de la revisión de Brayan del [PR #14](https://github.com/juliodparada-bit/plataforma-refugios-fauna-domestica-bogota/pull/14). **No se fusiona en este expediente.** En `main` el tope de 80 sigue en el servicio y en el DTO (CP-17, CP-18, CP-24).
