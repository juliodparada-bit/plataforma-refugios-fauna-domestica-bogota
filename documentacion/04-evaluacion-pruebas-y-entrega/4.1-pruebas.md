## Qué se prueba

| Tipo | Dónde | Qué cubre |
|---|---|---|
| Unitaria | `api/src/dominio/puntaje.spec.ts` | RF-09: número 0–100 y frase de choque |
| Integración e2e | `api/test/app.e2e-spec.ts` | `GET /localidades` contra Postgres en `5433` |
| Manual (rúbrica) | Cliente en `5173` | Login, cookie `sid`, roles 403, cinco CRUDs, especie canino/felino |

Comando unitario (en `api/`): `npm test`.  
Comando e2e (Postgres arriba): `npm run test:e2e`.

## Casos negativos obligatorios

| Caso | Resultado esperado |
|---|---|
| Especie distinta de canino/felino en `POST /animales` | 400 (DTO `PublicarAnimalDto` + enum Prisma) |
| Entidad sin sello publica animal o ítem | 403 |
| Adoptante dispara `POST /animales` | 403 |
| Login con clave mala | 401 genérico (no revela si el correo existe) |
| Registro sin casillas de términos / Ley 1581 | No hay INSERT |

## Lo que no se prueba aquí

Pasarela, Nequi, app nativa, alta disponibilidad 24/7, pruebas con un refugio piloto real (entrevista de campo pendiente).
