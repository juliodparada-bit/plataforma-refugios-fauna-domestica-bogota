## 3. Primer arranque (este es el camino)

```bash
# Postgres
podman start refugios-pg
# Primera vez (elige uno):
#   podman compose -f compose.yml up -d
#   docker compose -f compose.yml up -d
# Si no hay plugin compose:
#   podman run -d --name refugios-pg \
#     -e POSTGRES_USER=refugios -e POSTGRES_PASSWORD=refugios_dev \
#     -e POSTGRES_DB=refugios -p 5433:5432 \
#     -v refugios_pg:/var/lib/postgresql/data postgres:16-alpine

# API
cd api
npm install
cp .env.example .env
npm run prisma:migrate
npm run prisma:seed
npm run start:dev

# Web (otra terminal)
cd web
npm install
npm run dev
```

Abro [http://localhost:5173](http://localhost:5173). Vite reenvía `/api` a `http://127.0.0.1:3000` (`web/vite.config.ts`). Diapositivas T6: [http://localhost:5173/sustentacion](http://localhost:5173/sustentacion) (guion [4.5](../04-evaluacion-pruebas-y-entrega/4.5-sustentacion.md)).

No se quitan migrate, seed ni lint: `npm run prisma:migrate`, `npm run prisma:seed`, `npm run lint` (API; el lint sale con cientos de avisos de estilo, [4.7](../04-evaluacion-pruebas-y-entrega/4.7-calidad-y-deuda.md)).

## 4. Variables de entorno

Fuente: `api/.env.example`. `.env` no va al Git.

| Variable | Uso |
|---|---|
| `DATABASE_URL` | PostgreSQL en **5433**, usuario/base `refugios` |
| `JWT_SECRETO` | Firma del JWT (cookie `sid` y Bearer) |
| `WEB_ORIGEN` | Orígenes **extra** de CORS. Por defecto ya van `localhost` y `127.0.0.1` en 5173 y 4173 |
| `PUERTO` | API (3000, escucha en `0.0.0.0`) |
| `VALIDADOR_CLAVE_INICIAL` | Clave del validador al sembrar |

Sesión: cookie `httpOnly` `sid` (web). Flutter: cuerpo `{ token, usuario }` y cabecera `Authorization: Bearer`. Si hay ambas, gana la cookie (`api/src/auth/token.ts`). No hay pasarela.

## 6. App Flutter (`mobile/`)

Companion de las mismas pantallas. No cambia Postgres ni el puerto 3000.

```bash
flutter run --dart-define=API_URL=http://127.0.0.1:3000  # simulador iOS
# Teléfono: IP LAN del PC, ej. http://192.168.1.20:3000
```
