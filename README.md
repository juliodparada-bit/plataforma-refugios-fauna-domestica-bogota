# Plataforma digital para la gestión integral de refugios de fauna doméstica en Bogotá

Proyecto formativo del tecnólogo **ADSO** (SENA, código 228118), ficha **3228973 B**, modalidad **presencial nocturna (mixta)**.

Marca propuesta: **Mestizo**. Ámbito: área urbana de Bogotá; caninos y felinos domésticos.

## Cómo leer el expediente

Toda la documentación está en [`documentacion/`](documentacion/00-indice-maestro.md). Empieza por el [índice maestro](documentacion/00-indice-maestro.md) y ábrelo en vista previa de Markdown (`Ctrl+Shift+V`).

Orden: **1.1 → 1.2 → 1.3 → 2.1 → 2.2 → 2.3**. El código de producto se construye en la fase 3; todavía no hay aplicación implementada.

## Alcance del prototipo

Verificación de entidades, catálogo con historia, postulación corta, listas de deseos en especie y bloqueo de fauna no doméstica. Este prototipo **no recauda dinero**.
